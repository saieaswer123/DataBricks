# 📚 Databricks & PySpark Fundamentals

This directory contains my foundational learning materials, scripts, and practice notebooks for mastering data manipulation using PySpark on Azure Databricks. 

## 🎯 Objective
To build a strong grasp of distributed data processing, DataFrame transformations, and SQL logic within a Databricks workspace.

## 📂 Contents

### Notebooks
* **`Day-1 to become a masker in databrickes 2025-11-01.ipynb`**: Introduction to the Databricks environment, cluster configuration, and basic PySpark DataFrame operations.
* **`day2_for_learning_movies_table 2025-11-20.ipynb`**: Hands-on exercises focusing on reading CSV files, applying schema, and performing basic data exploration.

### Practice Datasets
A collection of sample CSV files used for testing joins, aggregations, and window functions:
* `department.csv` / `department_1.csv`
* `employee.csv` / `emp_1.csv` / `emp_1.csv`
* `movies.csv`
* `orders.csv`

## 🚀 Key Skills Demonstrated
* **Data Ingestion**: Reading CSV data from Azure storage into PySpark DataFrames.
* **Transformations**: Filtering, grouping, joining, and handling null values.
* **Data Types**: Understanding PySpark schema definitions (`StructType`, `StructField`).
